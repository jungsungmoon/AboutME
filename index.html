SSAFY AI 피드백 시스템

RUNNING · aibot.ssafy.io 멀티캠퍼스 · 1인 기획/개발

시험 답안을 AI가 채점하고, 학생별 약점에 맞는 복습까지 자동 생성하는 시스템입니다.

PROBLEM

900명의 코딩·서술형 답안을 강사가 수작업 채점 — 결과까지 수일, 개인별 피드백은 불가능했습니다.

SOLUTION

제출 즉시 LLM이 루브릭 기반으로 채점하고, 취약점 리포트·복습 퀴즈·튜터 챗봇을 자동 생성합니다.

HOW IT WORKS — 시험 종료부터 복습까지 5단계

답안 수집·파싱코딩·서술형 답안을 문항 단위로 자동 분리
비동기 큐잉900명 동시 제출 트래픽을 큐로 분산
LLM 자동 채점루브릭 기반 채점 + 누락 개념 태깅
개인 리포트개념별 이해도 레이더 차트 자동 발행
맞춤 복습틀린 개념만 겨냥한 퀴즈·튜터 챗봇

LabHub 만족도 분석 시스템

RUNNING 멀티캠퍼스 · 기획/파이프라인 개발

수천 건의 만족도 설문을 AI가 읽고, 불만 신호를 대시보드 한 장으로 보여줍니다.

PROBLEM

매주 50개+ 설문 엑셀과 주관식 수천 건을 운영진이 직접 읽고 요약 — 중요한 불만 신호는 늦게 발견됐습니다.

SOLUTION

업로드만 하면 파싱 → 감성 분석 → 시각화가 자동으로 이어지는 파이프라인을 만들었습니다.

HOW IT WORKS — 엑셀 뭉치가 대시보드가 되기까지 4단계

파일 일괄 수집양식이 제각각인 설문 50+개 업로드
비동기 파싱표준 스키마로 정규화·통합
LLM 감성 분석긍/부정 분류와 핵심 불만 요약
추이 대시보드주차별·트랙별 추이 시각화
